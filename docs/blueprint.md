# **App Name**: Leads Navigator

## Core Features:

- Leads Table: Display leads in a sortable, searchable table.
- Lead Management: Enable adding, editing, and deleting leads via forms that integrate with the https://crm.borderiq.org/api API.
- Dashboard Visualizations: Display key metrics related to leads, such as lead source distribution, in clear, concise charts.

## Style Guidelines:

- Dark background for overall interface.
- Accent color: Orange (#FFB347) for primary actions.
- Secondary accent colors: Yellow (#FFDA63) and Red (#F44336) for alerts and important metrics.
- Large, bold typography for key metrics.
- Metric blocks with rounded corners.
- Consistent padding and margins for all elements.
- Simple, clear icons for navigation and actions.
- Subtle transitions and animations for feedback.
